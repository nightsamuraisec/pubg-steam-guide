## 📌 Proje Hakkında (About The Project)

**PUBG Steam Guide**, tarayıcıda açılan ücretsiz bir rehber uygulamasıdır — kurulum yok, hesap yok, indirme yok.

### Hemen kullan

👉 **[https://nightsamuraisec.github.io/pubg-steam-guide/](https://nightsamuraisec.github.io/pubg-steam-guide/)** — linke tıkla, oyna.

| Bölüm | Ne işe yarar? |
| --- | --- |
| **Çanta** | Squad çantası planla, ağırlık limitini gör, link ile paylaş (`?bag=`) |
| **Harita** | Gizli bodrum / servis odası rehberi (Erangel, Miramar, Taego…) |
| **Orijinal** | Tam ekran orijinal haritalar |
| **Araçlar** | Araç istatistikleri + benzin / bidon hesabı |
| **Drop** | Care package ve loot rehberi |
| **Bilgi** | Steam / oyun ipuçları |
| **Kademe Level** | Hayatta Kalma Ustalığı 5 kademe hesaplayıcı |
| **Dereceli** | Ranked RP aralıkları, ödüller ve hesaplayıcı |

- 🌐 **TR / EN** — sağ üstten dil değiştir
- 📱 Mobil ve masaüstü uyumlu, koyu tema
- 🔗 Çanta planını URL ile arkadaşına gönder

> Fan aracıdır; PUBG / Steam / Krafton ile bağlantılı değildir. Veriler tarayıcıda kalır.

- 🚗 Araç ve benzin rehberi

## 🚀 Başlarken (Getting Started)

### Canlı sürüm (önerilen)

Tarayıcıda aç: **[nightsamuraisec.github.io/pubg-steam-guide](https://nightsamuraisec.github.io/pubg-steam-guide/)**

### Yerelde çalıştırma (isteğe bağlı)

```bash
git clone https://github.com/nightsamuraisec/pubg-steam-guide.git
cd pubg-steam-guide
npx --yes serve .
```

---

## 📖 Kullanım (Usage)

Çanta planla → paylaşım linkini kopyala. Rehber sekmesinden harita/filtre kullan.

### README ekran görüntülerini güncelleme (maintainer)

```bash
node tools/capture-screenshots.mjs
```

Veya `main`'e push — `.github/workflows/screenshots.yml` arayüz değişince `screenshots/` klasörünü günceller.
